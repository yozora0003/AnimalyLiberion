## Unreal Engine 5 C++: ターン制3DRPG コア実装（雛形）

このフォルダは UE5 プロジェクトそのものではなく、`Source/` 配下に配置する想定の C++ 実装一式です。

### 使い方（既存の UE5 プロジェクトに組み込む）

- 既存の `<ProjectName>.uproject` があるプロジェクトに、このリポジトリの `Source/AnimalyLiberion` を `Source/<ProjectName>` に合わせてリネームしてコピーしてください。
- その後、UE エディタで C++ クラスを再生成（または Visual Studio / Xcode でビルド）すると反映されます。

### 実装されている要件

- ターン制（移動 or スキル使用でターン消費）
- 攻撃は 4 スロットにセットされたスキルで実行
- 物理体力 / 精神体力（精神体力 0 で特殊処理）
- ステータス：物理体力、精神体力、物理攻撃/防御、精神攻撃/防御、スピード
- 行動順：スピード基準
- ダメージ：攻撃力と防御力から算出
- 敵：ミニマックス法（簡易シミュレーション）で行動選択
